## 📝 How to Use

### Running C/C++ Programs
```bash
# Using GCC (for C)
gcc filename.c -o output
./output

# Using G++ (for C++)
g++ filename.cpp -o output
./output
```

### Running Python Programs
```bash
python filename.py
# or
python3 filename.py
```
